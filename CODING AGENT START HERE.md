All source, logos, previews and branding files are saved locally. A running localhost server is optional and is not required to retain the design. Use the frozen ZIP in Design to transfer the approved reference as one package. The separate research folder and technical/project documents remain in the project root.

The reference is a prototype with synthetic prices and demonstration history. Approved design does not establish a live data source, actual profits, sportsbook integrations or production readiness. Keep the calculator, saved scenarios and pair-performance ledger distinct. Performance was added after the original blueprint; its UI is approved and its production persistence/settlement model must be designed explicitly.
