# System diagrams

Editable FigJam board: https://www.figma.com/board/aKWex1r82c2rxTFqPIekMG

The coloured UML class model uses separate compartments for names, attributes and operations. Blue identifies adapters, teal services, purple calculation logic, orange persistence and green entities. Selected dependencies, realization and composition relationships are shown; it is a proposed design rather than an implemented class inventory.

Ushio Odds Figma UML Class Diagram.png is a native board screenshot. Ushio Odds System UML Class Diagram.svg and Ushio Odds System UML Class Diagram.png are local vector/raster companions generated from the same model data, not native board exports. The board also contains the runtime sequence view. No automatic wagering component is included.
